# 🧠 JavaScript Quiz App

An interactive **JavaScript Quiz App** built using **HTML, CSS, and JavaScript**.
The app allows users to test their JavaScript knowledge through multiple-choice questions with a **30-second timer for each question**, instant feedback, score tracking, and a Play Again option.

## 🚀 Features

* 🎯 20 JavaScript multiple-choice questions
* ⏱️ 30-second timer for each question
* ✅ Instant correct/wrong answer feedback
* ❌ Displays the correct answer when the selected answer is wrong
* 📊 Automatic score calculation
* 🔄 Play Again option after completing the quiz
* 🖱️ Interactive answer selection
* 📱 Responsive and user-friendly interface
* ⚡ Dynamic questions and choices using JavaScript DOM manipulation

## 🛠️ Technologies Used

* **HTML5** – Structure of the quiz
* **CSS3** – Styling and responsive design
* **JavaScript** – Quiz logic, timer, DOM manipulation, answer checking, and score calculation

## 🎮 How It Works

1. Click the **Start Quiz** button.
2. A JavaScript question with four options will appear.
3. Select your answer.
4. Click **Next** to submit the answer.
5. The app checks your answer and displays instant feedback.
6. You get **30 seconds** for each question.
7. If the timer reaches zero, the quiz automatically moves to the next question.
8. After all 20 questions, your final score is displayed.
9. Click **Play Again** to restart the quiz.
